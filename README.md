## 🔧 Инженерный подход

В разработке для меня важны не только реализация функциональности, но и понимание того, как система работает целиком.

- **Самостоятельное решение задач.** Исследую проблему, анализирую существующий код, рассматриваю варианты реализации и проверяю результат.
- **Работа с существующими системами.** Разбираюсь в сложившейся структуре приложений, работаю с legacy-кодом и вношу изменения с учётом имеющихся ограничений.
- **Работа с базами данных.** Использую SQL и ORM для получения и изменения данных, исследую поведение запросов и возможности их оптимизации.
- **Разработка API.** Работаю с серверной логикой, обработкой запросов, валидацией данных и взаимодействием компонентов.
- **Изучение технологий на практике.** Предпочитаю не ограничиваться чтением документации, а проверять знания при решении реальных технических задач и разработке собственных проектов.
- **Архитектурное мышление.** Интересуюсь разделением ответственности между компонентами, организацией взаимодействия сервисов и возможностью развивать систему без излишнего усложнения.

## 🚀 Основной проект

### [NeuroHunter](https://github.com/LeeGeller/neurohunter)

**Open-source система персонализированного поиска и анализа вакансий.**

Цель проекта — разработать систему, которая оценивает вакансии не только по профессиональным навыкам кандидата, но и по обязательным ограничениям, предпочтениям и совместимости рабочей среды.

В основе проекта — несколько взаимодействующих компонентов, использующих Python, Go, базы данных и локальные языковые модели.

В рамках проекта я работаю над:
- разделением ответственности между компонентами;
- моделями данных и обработкой пользовательских профилей;
- backend API и взаимодействием с хранилищами;
- интеграцией локальных LLM для структурирования информации;
- асинхронной обработкой задач;
- контейнеризацией и конфигурацией окружения.

NeuroHunter — площадка для самостоятельной практики в проектировании и разработке backend-систем, интеграции технологий и проверки инженерных решений.

Проект находится в активной разработке.
