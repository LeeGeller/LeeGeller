## 🚀 Основной проект

### [NeuroHunter](https://github.com/LeeGeller/neurohunter)

Open-source проект для персонализированного поиска и анализа вакансий.

**Основная идея:** оценивать вакансии с учётом профессиональных навыков кандидата, обязательных ограничений и предпочтений относительно рабочей среды.

Проект объединяет Python, Go, базы данных и локальные языковые модели. Сейчас развивается архитектура системы и её основные компоненты.
